# PlayPK Mobile (Expo)

Customer app for searching and booking sports venues.

## Run

```bash
# Terminal 1 — API
npm run dev:api

# Terminal 2 — Expo
npm run dev:mobile
```

Then press `i` (iOS simulator), `a` (Android), or scan the QR with Expo Go.

Demo player: `player@playpk.demo` / `PlayPK@player1`

Set `EXPO_PUBLIC_API_URL` in `.env` to your machine LAN IP when testing on a physical phone
(e.g. `http://192.168.1.10:4000`).
